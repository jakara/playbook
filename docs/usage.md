# 使用指南

## 体验教程

打开 Playbook，播放首页的「Playbook 使用教程」。教程使用合成练习数据，默认在内置浏览器中播放，可以播放整本，也可以只看一个 Section。

讲到 Skill 安装时，教程会暂停自动操作，让你选择安装目标并亲自点击安装。点击继续或等待结束会恢复讲解；是否安装成功，以安装结果为准。

## 安装 Skill

在「Skill 安装」页选择 Codex 或 Claude Code，再选择个人范围或指定项目。

- 个人范围适用于该框架下的所有项目。
- 项目范围由你选择项目根文件夹，不要求先添加到 Playbook，也不要求已有 `.playbook.json`。

检查目标路径和已有版本后点击安装。更新已有内容会先备份；检测到本地修改或冲突时，需要明确选择替换。安装器保留符号链接，不向链接目标写入。

安装包含主入口 `$playbook-wright` 和兼容入口 `$playbook-playwright`。完成后，在智能体中重新加载 Skills 或开启新会话，再调用主入口。安装路径与命令行方式见[安装指引](../install.md)。

## 编写演示

把想演示的目标、观众和流程告诉自己的智能体，例如：

> 使用 $playbook-wright，演示课程查找与任务预览，控制在三分钟内。查询结果出现后，让观众操作十秒，再继续讲解。

Skill 可以从需求、手工操作或已有 Playwright 测试用例出发，生成清单、脚本和 Profile。你也可以让智能体调整讲稿、提示位置、光圈、打码、语音和章节顺序。

文件保存在业务项目中：

```text
project/
  .playbook.json
  demos/
    flows/*.playbook.ts
    profiles/*.profile.ts
    audio/
```

清单组织内容和播放顺序；脚本保存操作、断言与讲解；Profile 提供服务地址、登录、数据准备和资源释放。[入门样例](../examples/starter/.playbook.json)可作为接入参考，字段和兼容要求见 [Skill 契约](../skills/playbook-wright/references/contract.md)。

## 添加与浏览项目

点击「添加项目」，选择包含 `.playbook.json` 的目录。左侧显示项目文件夹和 Book，打开 Book 后，通过右侧 Section Tab 查看脚本和步骤。可以按名称、摘要、标签或角色搜索。

智能体修改文件后，点击「从磁盘刷新」重新读取。播放使用启动时构建的快照，文件更新在下一次播放时生效。

移出项目只取消客户端登记。删除 Book 会先备份清单，再移除对应定义，保留脚本、Profile、录音和运行记录。内置教程与入门样例同样可以移出或删除；重新添加内置项目会恢复项目登记，已删除的 Book 需要另行恢复。

## 播放与控制

选择已有 Profile 后，播放单个脚本，或点击 Book 的「播放全部」、Section 的「播放本节」。批量播放按清单顺序执行，共享 BrowserContext；各脚本创建新页面，单独准备和释放资源，前段清理未成功时不会启动后段。

内置模式把页面留在客户端；外部模式打开本机 Google Chrome 的独立会话。需要多窗口、扩展或特殊 Chrome 参数的流程，应选择外部模式并验证兼容性。

默认快捷键为 `⌘⌥P`：空闲时播放当前选项，运行中暂停或继续。外部悬浮条可以拖动、收起，约三秒无输入后隐藏，活动后重新显示。内置模式使用窗口顶部控制栏。

暂停会等待当前操作到达可暂停的位置。停止会取消后续步骤，再等待 Profile 清理并保存结果，已经发出的业务操作不会自动撤回。正常关窗或退出也会协调停止与清理。

## 邀请观众操作

脚本可以在讲解后交还操作权，并设置倒计时或等待手动继续。交接期间隐藏提示和蒙层；用户输入会重置计时，选择文件夹和安装期间暂停计时。

继续或倒计时结束后，脚本仍会检查结果。需要明确完成某项任务时，应让智能体添加有效断言，并设置合适的超时策略。配置方法见[内置播放与手动操作](../skills/playbook-wright/references/interaction.md)。

## 语音与打码

启用朗读后，播放器默认读取开场和各步讲解；也可逐段更换讲稿、使用本地录音或静音。macOS 朗读使用本机声线。录音须保存在项目内，支持 WAV、MP3、M4A 和 OGG，单文件不超过 20 MB。

打码可按页面选择器遮盖或模糊指定区域。它只改变显示效果，页面和接口中的原值仍存在；需要保护的信息应先在演示环境中脱敏，讲稿和录音也应检查。

参数与示例见[可用功能](../skills/playbook-wright/references/capabilities.md)。

## 导出 PPTX

在 Book、Section 或脚本详情点击「导出 PPTX」，选择保存位置。导出会重新执行流程，生成 16:9 截图课件，嵌入语音并按讲解安排换页，讲稿写入演讲者备注。取消保存窗口不会启动执行。

含手动交接的流程需要另备纯自动版本。导出失败或停止会保留旧目标文件；保存失败也不表示已经执行的业务操作被撤回。结果和记录中可打开 PPTX 或显示所在文件夹。

在实际使用的演示软件中检查声音和换页节奏。截图中的组件不可逐个编辑。详细规则见 [PPTX 导出](../skills/playbook-wright/references/pptx-export.md)。

## 查看结果与修复

运行记录显示结果、步骤、耗时和错误。复制上下文后，可以交给自己的智能体定位和修复；客户端不会自动发送这些内容。

清理失败、超时或结果未知时，先查看清理回执。只有 Profile 声明了精确资源句柄和幂等恢复入口，并通过版本与归属核对，才可从记录中恢复。旧 Profile 没有恢复声明时，需要人工检查，应用不会扫描删除业务资源。

接入测试、回放与故障排查方法见[检查与排错](verification.md)。
