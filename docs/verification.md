# 检查与排错

## 环境检查

正式安装包支持 macOS Apple Silicon。应用自带运行环境；外部播放和 PPTX 导出需要本机 Google Chrome。内置播放使用应用内的浏览器。安装与首次启动说明见[安装指引](../install.md)。

业务服务、账号、依赖和 Profile 由项目提供。先确认目标环境可访问，再播放自己的流程。

## 首次使用自检

1. 打开应用，播放内置教程，检查提示、页面操作和讲解。
2. 暂停后继续，检查页面与语音恢复；停止后查看运行结果和清理状态。
3. 安装 Skill 后，在智能体中重新加载，确认 `$playbook-wright` 可用。
4. 添加自己的项目，检查 Book、Section、脚本及 Profile 是否完整，再运行一个适合重复演示的流程。

教程使用合成数据。项目接入后，还需检查自己的登录、权限、业务结果和资源释放。

## 常见问题

### 项目或脚本无法播放

检查所选文件夹根目录是否有 `.playbook.json`，清单引用的文件是否存在。修改后点击「从磁盘刷新」。

标题、步骤说明和其他发现元数据需要使用静态对象；不支持通过变量、spread 或运行时计算生成。动作和断言仍使用 TypeScript 函数，详见[技术架构](architecture.md#工作区发现契约)。

源码开发环境可运行：

```sh
npm run build
npm run check:examples
```

应用的 `--check-workspace <project-root>` 入口可检查元数据、引用和构建，不执行 Profile 或浏览器步骤。输出中的 `typecheck: "not-run"`、`browser: "not-run"` 表示尚未做对应检查。

### Skill 已安装，但智能体没有发现

确认安装目标与智能体实际打开的项目一致。项目安装应指向项目根目录，安装器会追加框架对应的 Skills 子目录。检查主入口和兼容入口是否均已安装，再重新加载 Skills 或开启新会话。

检测到本地修改或符号链接时，先按安装页提示处理；不要通过删除未知目录来绕过冲突。详细步骤见[安装指引](../install.md)。

### 暂停或停止没有立即结束

进行中的操作需要到达运行边界才能暂停。停止会取消后续步骤，并给 Profile 独立的清理时间；清理期间浏览器可能继续保留，以便取证和释放资源。

查看记录中的执行与清理状态。强制结束进程不能保证清理回调执行，重启后可能需要人工核对。恢复接口及旧 Profile 兼容规则见[生命周期](../skills/playbook-wright/references/lifecycle.md)。

### 快捷键或悬浮条不符合预期

默认快捷键为 `⌘⌥P`。若注册失败，检查客户端提示及其他应用的快捷键占用。外部模式显示可拖动、可收起的悬浮条，内置模式使用顶部控制栏。

检查当前模式、显示器和全屏状态。跨应用焦点、键盘输入和多显示器行为需要在实际使用的桌面环境中确认。

### 没有声音，或讲解被截断

先检查客户端「语音讲解」开关。默认开启时，未配置旁白的脚本也会朗读开场和步骤说明；显式静音的流程或步骤仍保持静音。确认系统已安装所选声线，输出设备正常。使用录音时，检查文件是否位于项目内、格式受支持且未超过 20 MB。

播放器等待语音和最短停留均完成后才操作。调整讲稿时，应检查实际播放结果；只增加固定等待时间不能修复媒体错误。

### PPTX 的声音或换页不正确

使用目标演示软件打开 PPTX 并实际放映，检查旁白是否完整、换页是否发生在讲解结束后，以及备注是否正确。静态预览或 PDF 不包含完整的音频和放映计时行为。

导出会重新执行流程。失败或停止后，先查看运行记录和清理状态；旧目标文件会保留。详细参数见 [PPTX 导出](../skills/playbook-wright/references/pptx-export.md)。

## 源码检查

在产品仓库运行：

```sh
npm ci
npm run check
npm run desktop:check
npm run desktop:smoke
npm run test:pptx
```

这些检查覆盖核心、类型、合成示例及桌面流程。业务项目仍需运行自己的类型检查、Playwright 测试和实际回放；画面、声音、快捷键及原生对话框需要在目标环境中确认。

提交问题时，请附应用版本、运行模式、复现步骤和已脱敏的错误信息。分享日志、截图、讲稿、录音或运行上下文前，移除个人路径、账号、访问凭据和业务数据。
