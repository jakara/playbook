# Playbook 产品方案

日期：2026-10-21。本文为 v0.3.0 功能与边界说明，随包 Skill 为 0.5.0；具体通过项、版本和证据见 [verification.md](verification.md)，文档中的功能描述不替代运行验收。

## 产品定位

Playbook 是由智能体创作、供用户查看与播放的自动演示工具。用户使用自己的智能体配合 Playbook Skill，将业务目标、手工讲解或已有 Playwright TC 整理成 scripts；Electron 客户端读取业务文件，提供项目浏览与真实浏览器播放。

AI 原生体现在需求梳理、生成、讲解与效果调整、编排、转换和修复都在用户熟悉的智能体中完成。Skill 是创作入口，客户端是项目浏览、播放器和反馈入口，不增加模型账户、聊天或另一套智能体运行时。

演示先介绍目标，以章节、箭头、蒙层、柔边光圈和演示光标引导视线，可遮盖指定页面区域并同步播放讲解，再执行真实操作并检查结果。动作与断言保持 Playwright 原生形式，可继续在测试中复用。进度与播放控制由客户端原生悬浮条提供，业务页面只注入引导呈现。

艺工是业务试点方向。脚本、Profile、URL、账号与数据留在艺工业务仓库；产品内置的课程工作台是合成教学样例，不等同于艺工系统或业务验收证据。

## 职责与资产

| 动作 | 负责方 | 当前客户端作用 |
|---|---|---|
| 确定观众、目标和业务路径 | 用户的智能体 + Skill | 浏览结果、复制修改上下文 |
| 新建、改名、拆分、合并和删除脚本 | 用户的智能体 + Skill | 发现变化并更新只读列表 |
| 调整说明、章节、节奏、方向、光圈、打码、语音与 Book/Section 顺序 | 用户的智能体 + Skill | 按支持的契约展示播放 |
| 编写定位、动作、断言与 Profile | 用户的智能体 + Skill | 选择已有环境、构建执行 |
| TC 与 scripts 转换 | 用户的智能体 + Skill | 播放产物、提供结果 |
| 搜索、播放、暂停、继续、停止、重播 | 客户端 | 直接操作 |
| 随包 Skill 安装更新 | 客户端，按用户明确选择 | 预览目标、检查冲突、备份核验 |

`.playbook.json`、脚本、Profile、原测试和转换报告归业务工作区，随业务代码演进。运行缓存和记录归应用本机数据；Skill 包归产品维护并按所选目标安装。客户端没有第二份可编辑脚本库。

## 统一组织概念

对用户统一称为“项目”：添加的是包含 `.playbook.json` 的业务目录，契约/API 中的 workspace 也是这个目录，不与“资料库”并列。项目只是存放 Book 的本地文件夹。左侧仅显示“项目文件夹 → Book”两层树；Section 与脚本不进入导航树。Book 内按 **Section → 脚本** 组织：Book 对应一整套演示，Section 对应其中的主题段落，脚本是可执行的核心操作流程。

进入项目先展示 Book 列表；打开一个 Book 后，左侧保留窄的标题树，右侧用主要空间展示内容。Section 采用 Tab，每个 Tab 下平铺脚本，可进一步查看操作步骤。

Book 和 Section 都可播放全部：Book 的“播放全部”和 Section 的“播放本节”。Book 按 sections 数组依次执行各章，每章再按 scripts 数组依次执行；Section 只执行自己引用的脚本。脚本引用使用稳定 ID，不复制动作与断言，单个脚本仍可播放。容器编排由智能体修改业务清单，客户端只读展示。

整次播放选择一个已有 Profile，所有脚本须与它的数据模式和身份要求兼容。每个脚本独立 prepare/release，不隐式继承前一个脚本的页面或内存状态。旧 demos 清单兼容显示为 Book 和 Section，不自动迁移或改写用户文件。

添加/移除项目只改变应用登记；浏览和播放不回写脚本、清单或源码。业务只读另由脚本声明：点击播放执行可信本地 TypeScript，其动作可能写入业务系统。

## v0.3 端到端流程

### 安装 Skill

1. 进入“Skill 安装”，选择 Codex 或 Claude Code。
2. 选个人范围，或选自己的已登记项目；内置样例不作安装目标。
3. 核对实际目录、随包/已有版本、文件数和状态，再点击安装。
4. 更新先备份；修改/冲突须勾选“先备份再替换已有内容”；软链接不安装。
5. 在自己的智能体中确认可用。首版校验文件安装，不探测智能体加载。

Skill 随应用交付，无需另行下载。每次只写选定目标，不自动改全局规则、hooks、模型设置或凭据。备份附恢复材料，首版无一键恢复界面。

### 交给自己的智能体创作

用户描述实际意图，例如：“给首次使用的老师演示查找课程和预览任务，三分钟以内，可以参考已有 TC。”

Skill 读取项目、测试和环境，优先复用已有资产，只补齐会改变结果且无法自行核验的信息。智能体维护脚本、Profile 与清单，依据真实页面和业务预期编写动作与断言；简单需求不强制长表或额外计划文档。

当前发现要求 `export default definePlaybook({ ... })` 等默认 literal 元数据；标题、要求和步骤说明不能依赖变量、spread 或运行时计算。动作与断言仍是 TypeScript 函数。

Skill 可从自然语言、手工流程或 TC 出发；转换须核对 fixture、认证、事件顺序、数据、断言和清理。产品不承诺任意 TC 一键全自动转换，也不以构建成功替代业务验证。

光圈柔边、打码与语音也由智能体修改业务脚本，不增加客户端效果编辑器。Skill 依据实际页面确定 CSS 遮盖目标，按用户意图选择本地朗读或已有录音，帮助整理适合观众的讲稿。语音默认关闭，已有脚本无需迁移；清单与脚本仍使用 `schemaVersion: 1`。

### 查看与播放

1. 初次打开可播放内置项目；业务接入时添加包含 `.playbook.json` 的目录。
2. 选择项目文件夹时，右侧展示 Book 列表；打开 Book 后，通过 Section Tab 查看平铺的脚本和步骤。可搜索名称、摘要、标签和角色，查看环境、操作影响和重播要求。
3. 选择已有运行方式，播放脚本或点击 Book/Section 的“播放全部”。应用构建本轮快照，独立 Chrome 展示讲解与自动操作，不使用内嵌 WebView。
4. 每步说明可同步播放语音，讲解与最短停留均完成后再执行 `run` 和 `verify`；断言或语音失败不继续。支持暂停、继续、停止和终态从头重播，语音跟随控制。
5. Book/Section 按既定顺序串行运行，各脚本重新准备页面上下文，不隐式共享内存状态。

原生透明置顶悬浮条展示当前流程、步骤和进度，提供播放/暂停与停止。文字与空白区域可拖动，右侧按钮可收成保留暂停/继续的小条并再次展开。位置与收起状态在本次应用会话中保留，不随鼠标活动回到默认位置。约 3 秒无鼠标或键盘活动自动隐藏，活动后显现。活动检测仅使用系统空闲时间和鼠标坐标，不记录按键内容，不额外安装全局键盘 hook。

默认系统快捷键为 `CommandOrControl+Alt+P`，Mac 显示为 `⌘⌥P`：运行时切换播放/暂停，继续时恢复并置前本轮受控 Chrome；空闲时播放主界面当前选择；终态可重播，仍经过原重播策略校验。客户端明确显示注册失败，不承诺与所有系统快捷键或第三方应用永不冲突。

暂停等待运行边界，不能撤回已发请求；停止不回滚已完成写入。需要重置的流程由 Profile 提供并声明恢复能力，单次执行流程不能直接反复运行。

### 观看效果与讲解

光圈边缘支持 0–100 px 渐变柔边，默认 24 px。流程级打码按 CSS 选择器遮盖 logo、姓名、数值等区域，默认不透明 cover，也可 blur；随滚动、重渲染、弹窗和同一主页面导航重新定位，仍允许原生交互。打码只改变画面，原始 DOM/API 数据仍存在；blur 也可能被辨识，不能作为安全脱敏。

语音可使用 macOS 本地文字朗读或工作区中的录音，无需云账户。启用流程朗读后默认读开场标题/摘要及各步 explain，可逐段覆盖讲稿、使用录音或静音。默认声线 Tingting、语速 185 words/min，声线须已在本机可用；其他平台本轮使用本地录音。录音支持 wav/mp3/m4a/ogg、单文件不超过 20 MB，路径限定工作区内并随运行快照冻结。播放失败明确停止，不能仅等待几秒假装有声音。

讲稿和录音不包含被遮盖的实际敏感值。独立 TC 导出与共享测试忽略这些纯呈现元数据，不将遮盖变成测试中的 DOM 修改，也不增加语音等待。

### 带着反馈迭代

详情与运行记录可复制修改、运行或错误上下文，用户自行粘贴给自己的智能体，例如：“预览多停四秒，提示放下方，保留原动作和断言。”

智能体修改文件后，项目定期重新发现；本轮使用启动时构建的代码和步骤信息，更新提示下一轮生效。应用不自动给智能体发消息或上传业务数据。

记录区分成功、失败、停止，保留进度、步骤、时间、环境与摘要。历史持久保存，界面展示最近 100 条；重启不自动恢复业务动作。首版尚无用户 trace、视频和脱敏导出流程。

| 正在播放 | 进度、状态、暂停/继续/停止、从头再播、来源更新提示、上下文 |

## 实现与信任边界

用户自己的智能体与 Skill 是创作端，本地业务文件是接口。Electron 管理只读界面、生命周期和分发；打包应用携带 Node 环境和产品依赖，不需另装 Node 或常驻服务。

演示依赖本机 Google Chrome 的独立会话，不连接日常浏览器。浏览时静态解析元数据，点击播放后执行可信本地代码；独立运行器不是代码权限沙箱。缓存和记录写应用目录，Skill 仅写明确选定目标。

原测试保留自身 fixture、配置、报告和 teardown，共享流程不代表运行器继承任意测试环境。实现细节见 [architecture.md](architecture.md)，实际命令见 [README](../README.md)。

## 当前能力与限制

| 能力 | 当前状态 |
|---|---|
| 创作 Skill | 已提供需求引导、创作维护、调整、转换和验证说明；质量需按真实任务评估 |
| 项目浏览 | 静态发现、搜索、两层文件夹/Book 导航、Section Tab、已有环境与定期变化发现 |
| 浏览器执行 | 已实现单主页面引导、原生动作断言、暂停继续停止重播 |
| 呈现与语音 | 可调光圈柔边、流程级 cover/blur 打码、macOS 本地朗读与工作区录音；实际覆盖范围见验收记录 |
| 批量播放与反馈 | Book/Section 有序批量播放、执行快照、记录和上下文复制 |
| 全局控制 | 原生悬浮条拖动与收起、按活动显隐、系统快捷键播放/暂停、恢复时置前受控 Chrome；跨平台效果需分别验收 |
| 安装器 | 已实现两个框架选定目标、版本/修改识别、备份替换和核验 |
| 分发 | 已有 macOS arm64 构建/打包命令；未签名公证，无自动更新 |

当前开发及实测范围为 macOS Apple Silicon，实际通过项以验收记录为准。未完成 Intel、Windows、Linux、干净机器验收。

本机须已安装 Chrome；业务服务、账号和外部依赖由项目提供。首版不捆绑浏览器，不自动安装业务依赖。静态发现限当前默认 literal 形态，变化发现不覆盖任意动态资产与所有依赖状态。

多页面、复杂 frame、上传下载和系统对话框引导及打码需专门适配验收。Playwright 的底层能力不等于播放器已覆盖其呈现。当前不含云协作、视频剪辑、云语音/克隆声线、浏览器扩展、原生桌面自动化、任意框架适配或任意 TC 全自动转换；系统文字朗读本轮限定 macOS。

## 验收口径

| 场景 | 判断依据 |
|---|---|
| 可运行 | 源码和打包应用分别检查启动、资源路径、Chrome 与退出回收 |
| 只读项目 | 浏览/播放前后业务资产摘要一致；变更、无效引用与不可读目录可见 |
| 控制 | 实际动作断言决定结果；暂停后无后续动作，停止不再调度，重播遵守数据策略；悬浮条显隐、跨窗口和快捷键注册失败按目标系统核验 |
| 视觉与语音 | 柔边实际渲染；打码在滚动、重渲染、弹窗/导航后跟随且不拦交互；语音内容、等待、暂停/继续/停止与失败传播分别验证，静态检查不等于已听到声音 |
| 固定版本 | 中途修改不改变本轮代码和步骤，下一轮重新构建 |
| 分层批量 | Book 展开章节再展开脚本，Section 展开自身脚本；既定顺序、同一 Profile、各脚本准备释放明确；旧 demos 兼容且不回写 |
| 安装 | 只写目标，修改不静默覆盖，备份可核验，软链接保留 |
| 反馈 | 结果区分清楚，可定位资产，不自动对外发送 |
| 测试复用 | 保留断言与生命周期，破坏预期会失败，未映射依赖列明 |
| 业务与发布 | 另验真实环境、权限、数据恢复、干净机器及分发 |

以上是完成判据，不是通过声明；逐轮实际结果由验收记录保留。
