# 脚本管理、讲解与呈现调整

当前可选功能与客户端行为见 [能力索引](capabilities.md)；涉及脚本字段时再核对契约。

## 定位要改的资产

优先使用用户给出的文件、流程 ID、步骤 ID 或客户端反馈的版本与错误；只给业务名称时搜索现有资产。相邻文案不是唯一标识，不能凭“第二步”去修改另一个脚本。若反馈版本与当前代码不同，先核对差异，保留历史运行结论。

变更只作用于用户要求的范围。Playbook 客户端是只读消费者；修改应由智能体写入业务侧资产，不修改客户端缓存来假装源文件已经更新。

## 管理与编排

- 改标题或文件名时保留稳定 ID，除非用户明确要改变身份；同步实际存在的 imports、演示引用和发现元数据。
- 拆分、合并和调整顺序前检查上下文、事件注册、前置数据与清理。不能让步骤失去依赖，或把同一个写入动作重复执行。
- 删除按用户授权范围处理，并先检查调用方。若仍被 TC 或演示引用，处理相应引用或说明需要保留的依赖，不删除不相关测试。
- 项目内编排使用 `.playbook.json` 的 books → sections → scripts，按流程 ID 引用已注册脚本，不复制 run/verify。Book/Section ID 使用 `[A-Za-z0-9._-]+`；Section 的组合键为 `bookId/sectionId`。改 ID 时同步真实引用，标题变化通常保留 ID。
- 调整 Book“播放全部”顺序时修改 sections 数组，调整 Section“播放全部”顺序时修改 scripts 数组。批量播放使用所选同一 Profile；同步默认 Profile、数据类别与依赖，各脚本所需角色必须由它实际提供。
- 每个脚本独立 prepare/release，拆分和重排时核对这一边界，不依赖前一个脚本的 page 或内存上下文。旧 demos 会兼容显示为 Book/Section；用户仅改讲解时不顺便迁移清单。

## 把自然语言调整映射到受支持字段

| 用户意图 | 当前契约中的处理 |
|---|---|
| 开场或章节更适合某类观众 | 调整 title、summary、explain 与 presentation.chapter；保持业务事实 |
| 讲解更短、更多解释或更突出功能价值 | 修改对应 explain，避免改变预期结果 |
| 某步多停留/少停留 | 调整该步 presentation.holdMs，毫秒为单位；“多四秒”在当前有效值上增加 4000 |
| 结果页面多展示几秒 | 调整该步 presentation.afterMs；它在 run 和 verify 成功后执行 |
| 所有步骤的讲解节奏 | 调整流程 presentation.defaultHoldMs；单步 holdMs 仍优先 |
| 开场长短 | 调整流程 presentation.openingMs |
| 提示移到下方/左侧等 | 修改 presentation.side 为 bottom/left 等现有枚举 |
| 展示哪个组件 | 仅在确需改变引导目标时调整 target；原业务 run 的定位不随之暗改 |
| 蒙层深浅、光圈大小、光标速度 | 调整流程 presentation.overlayOpacity、spotlightRadius、cursorMoveMs；数值范围见契约 |
| 光圈边缘更柔和 | 调整流程 presentation.spotlightFeather，0–100 px，默认 24；0 恢复硬边 |
| 遮盖 logo、姓名或敏感区域 | 在流程 redactions 增加稳定 CSS selector；默认 cover，可设 label/padding；blur 仅视觉模糊 |
| 一边演示一边讲解 | 流程 narration.enabled: true 复用开场与 explain；macOS 本地朗读可设 voice/rate |
| 某步另写讲稿、用录音或静音 | 步骤 narration 为 { text }、{ audio } 或 false；录音是工作区相对路径，不同时填 text/audio |
| 只关闭或替换开场语音 | 流程 narration.opening 为 false、{ text } 或 { audio }，不暗改其他步骤 |

当前有效停留值未写在步骤里时，先查实际播放器/演示配置的默认值；不能把“增加四秒”擅自解释为“总共四秒”。如果默认值无法确定且会影响结果，聚焦询问该值或预期总时长。时长与范围明确时自行处理。

区分点击前讲解的 holdMs 与结果验证后的 afterMs。未指定步骤 holdMs 时先用流程 defaultHoldMs，再用播放器默认 2600；afterMs 默认 550。需要“增加四秒”时在实际生效值上加 4000，不改成总共四秒。

桌面支持蒙层、柔边聚光、光标移动、点击效果、开场、章节、流程级打码、语音与上述时长字段；无呈现的 runPlaybook 参考执行器忽略这些元数据。当前没有通用主题或可视化脚本编辑器字段，不凭空添加键或修改业务页面 CSS。元数据改好但未实际播放时，只报告字段已更新。

语音调整先核对现有来源与用户意图：保留已有录音，不擅自换成本地朗读；新需求不明确时只问会影响交付的来源选择。macOS 文字朗读默认 Tingting、185 words/min，可用 rate 80–400 调整；其他平台本轮使用本地录音。录音相对工作区解析，支持 wav/mp3/m4a/ogg、单文件不超过 20 MB，作为运行快照冻结。语音和最短 hold 都完成后才操作，延长讲稿时不靠固定 hold 猜音频时长。暂停/继续/停止同步；播放失败应修复错误，不删语音假装原需求已完成。

打码是流程级配置，页面滚动、重渲染、弹窗及同一主页面导航后按 CSS 选择器重新定位。核对动态页面状态和选区，遮盖不拦截原生操作。cover 是默认不透明遮盖；blur 不能保证敏感值不可辨识。两者都不删除 DOM/API 数据，安全脱敏由业务环境保证。讲稿、explain、开场与录音也不得泄露被遮盖的实际值。TC 复用和独立导出忽略打码、柔边与语音，不把遮盖迁入测试逻辑。

下方进度和播放控制属于客户端原生透明置顶悬浮条，约 3 秒无输入后隐藏，鼠标/键盘活动后显现；默认系统快捷键是 `CommandOrControl+Alt+P`。播放栏可通过文字/空白区域拖动、收成小条并展开，位置和收起状态保留于本次应用会话；继续时恢复并请求置前受控 Chrome。这些是客户端行为，不属于脚本 presentation。不要在业务 DOM 再注入进度条、控制按钮或键盘 hook；快捷键注册失败属于产品/系统状态，不能靠改业务脚本修复。

呈现层只展示说明和光标，不执行第二遍业务点击。不把页面结果等待换成 holdMs，不用放宽断言让播放显得更流畅。逐字输入与 fill 的业务事件语义不同，不能仅为动画效果直接替换。

## 反馈修复与验证

失败先分清是业务状态、Locator、前置环境还是呈现层问题，使用实际记录和页面核对。客户脚本问题在业务资产中修复，通用播放器缺陷在产品范围内处理，不为视觉问题顺便改业务功能。

纯说明/呈现变更对比修改前后的 run/verify 与上下文，确认语义未改；执行必要的类型与清单检查。`--check-workspace` 只核对静态元数据、引用与编译，不是 typecheck/browser 通过。涉及目标、顺序、操作或前置数据时重验受影响流程；实际播放检查目标唯一性、说明遮挡和结果阅读阶段。打码增加滚动/弹窗/导航后的覆盖与交互核对，语音增加内容、等待与暂停/继续/停止核对。未渲染或试听时明确写出未验证范围。

客户端按运行快照播放，源清单、脚本、Profile 或静态相对 imports 更新影响下一轮；复制客户端上下文可取得流程、工作区、运行记录与 Skill 版本供用户自己的智能体接续；它只复制到剪贴板，由用户粘贴，不自动发送消息或启动另一智能体任务。核对实际文件/步骤 ID、源版本与失败记录，不改历史结论，也不宣称更新了当前正在执行的浏览器流程。
