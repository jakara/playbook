# PPTX 截图课件

适配客户端 v0.6（换页/音频修复自 v0.4.1），清单/脚本/Profile 仍为 `schemaVersion: 1`。此功能由本地客户端完成，不需云端模型或外部音视频转换器；仍需要 Chrome 和原脚本的运行环境。

## 使用与资产边界

含 `interaction.mode: 'manual'` 的脚本/Book/Section 当前会被明确拒绝导出；不能自动点击真人操作、跳过交接或将“继续/超时”作为成功截图。需要课件时，另建已授权的纯自动副本，移除或替换 manual，提供等价 run/verify，重新核对环境、写入与重播策略。原来的交互式培训脚本保持原语义，详见 [手动交接](interaction.md)。

1. 在客户端打开 Book、Section 或单脚本，选择已有 Profile，点击“导出 PPTX”。页面已说明导出会重新执行流程；系统保存窗口选择 `.pptx` 文件位置，取消不会执行。
2. 客户端构建本轮代码/录音快照，按原顺序执行 prepare、run、verify、release；仍受角色、dataMode、single-run 和 reset-required 条件限制。它不是从某次旧运行记录直接转换，不要因为“只是导出”绕过业务写入授权。
3. 全部步骤及释放成功后才生成并保存文件。失败或停止不发布半成品，不覆盖原目标；已执行的业务操作不会撤销。停止后的清理状态与崩溃回执沿用 [生命周期契约](lifecycle.md)，前段清理失败不继续后段或发布课件。保存失败时，运行记录说明操作已经执行，重试仍需遵守重播策略。
4. 完成页及运行记录提供“打开 PPTX”和“在文件夹中显示”。输出含屏幕内容、讲稿和语音，按用户授权决定保存/分发位置；不会自动发送给客户。业务脚本仍留在业务项目，产品代码留在产品仓库。

## 画面与换页

截图按固定 1440 × 810 视口生成 16:9 课件，图像铺满页面，不能在 PPT 中逐个编辑业务控件。逐页保留开场、脚本内部章节、操作前箭头/蒙层/光圈、操作后结果及最后完成提示。截图时固定引导层的淡入动画，保证卡片和箭头完整可见。开场/步骤在对应旁白开始前截图，目标步骤先为静态截图摆放光圈，再恢复真实演示光标；不在旁白结束后才取画面。结果在 verify 成功后截取，隐藏引导层，独立打码层继续生效；弹窗和导航仍按现有播放器适配边界核验。截图表现关键状态，不连续播放鼠标移动动画。

自动换页以当前脚本的名义节奏为基础，并为静态课件增加阅读和音频安全余量。先按下表计算基础时间：

| 页面 | 基础时间 |
|---|---|
| 每个脚本开场 | openingMs，默认 2800 |
| 新 chapter 提示 | min(1800, openingMs) |
| 有 target 的步骤讲解 | holdMs + cursorMoveMs + 250 |
| 无 target 的步骤讲解 | holdMs |
| 操作结果 | afterMs，默认 550 |
| 最后完成页 | 1800 |

最终停留时间取“基础时间、实际 WAV 音频长度 + 1000 ms、最短阅读时间”三者的最大值，再向上取整到整秒。章节和结果最短 2000 ms，开场/讲解/完成页最短 3000 ms；没有音频时不加音频余量。这样避免亚秒页面闪过和兼容播放器计时截断。课件可能比浏览器回放略长，不承诺毫秒完全相等；与完整讲解、可读画面及原始步骤顺序对齐。

holdMs 先取步骤值，再取流程 defaultHoldMs，再默认 2600；cursorMoveMs 默认 900。导出不计人工暂停、接口/导航等待、语音生成、截图和打包耗时；测试加速参数也不缩短课件时长。所有步骤仍按实际结果条件等待，不能用换页时间代替断言。需要更长阅读时间，增加原有 holdMs/afterMs，而不是更改业务动作。

## 语音与备注

- 复用当前 `narration.enabled`、开场覆盖、步骤 `{ text }` / `{ audio }` / `false`。未启用或显式静音的段落不凭空生成音频。
- 本机 TTS 与快照录音经 Chrome 解码为 PCM WAV，直接内嵌到 PPTX；每页使用独立 audioFile 媒体对象和自动播放时间线，在当前页播放一次；不使用切换音效充当旁白，不跨页循环。放映时隐藏媒体对象，换页结束本页音频，不依赖工作区录音路径或互联网。
- 开场备注优先自定义 narration.opening.text，否则使用 title + summary；步骤备注优先 narration.text，否则 explain。本地录音没有文本转录能力，备注取现有文案，智能体应核对讲稿与录音含义一致。结果页备注标识步骤结果，章节/完成页使用对应说明。
- 遮盖页面不意味着讲稿、备注和录音已脱敏，不能复述实际敏感值。PPTX 是可分享副本，事前核对演示数据与打码选择器，生成后抽查结果帧。
- 自动换页和声音使用标准 PowerPoint 放映设置。应在目标演示软件的幻灯片放映模式中播放并启用计时/声音；浏览器预览、PDF 或部分兼容播放器不等同于 PowerPoint 放映。

## 验证与调整

先核对脚本/清单，再实际导出；打开若干开场、箭头、弹窗和结果页，检查截图没有遮挡/泄露，备注与对应步骤匹配，音频完整且换页不截断。区分文件结构检查、页面渲染、真实浏览器动作与目标 PowerPoint 实机放映，不用其中一项替代其余项。没有目标软件时明确报告自动换页与可听声音尚未实机验收。

调整课件继续改已有 title、summary、explain、narration、chapter、holdMs、afterMs、cursorMoveMs、redactions 等字段；没有 `pptx`、`slides`、`autoAdvance` 等脚本字段。想在操作结果上配旁白，应保留该操作及 verify，再添加指向结果的观察步骤，不移动或复制业务点击。
